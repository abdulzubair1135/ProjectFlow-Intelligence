# Natural Mineral Design System

ProjectFlow Intelligence adheres to the **Natural Mineral Design System**, a calm, functional aesthetic utilizing earthy mineral tones, clean borders, and clear typography.

---

## Palette Tokens

| Token Name | Hex Code | Primary Usage | Prohibited Usage |
|---|---|---|---|
| **Deep Sage** | `#56664C` | Primary buttons, active tabs, progress fills | Never use as full-page background |
| **Mineral Sage** | `#78866B` | Secondary badges, subheadings, icon accents | - |
| **Limestone Ivory** | `#F4F2E9` | Main page canvas background | Never use for primary text |
| **Warm White** | `#FAFAF7` | Card surfaces, modals, table backgrounds | - |
| **Charcoal** | `#292D28` | Primary text and major headers | - |
| **Muted Slate** | `#5A6258` | Secondary body text, timestamps, meta info | - |
| **Stone Border** | `#E2E0D8` | Grid dividers, card borders, table separators | - |
| **Alert Red** | `#C84B31` | Critical risk warnings, destructive alerts | Do not use for non-critical elements |
| **Alert Amber** | `#D97706` | Approaching deadlines, warning tags | - |

---

## Strict Design Guidelines

1. **NO Brown Primary Elements**: Brown backgrounds, buttons, and navigation bars are strictly prohibited.
2. **NO Emoji Icons**: Emojis are strictly banned from UI navigation, headers, and status badges. All visual symbols must use Lucide vector icons or Android XML vector drawables.
3. **Empty States**: Screens with zero records must render a clean, explanatory empty state with a call-to-action button, rather than blank tables or broken layouts.
